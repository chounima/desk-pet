# AI 輔助產生角色美術

用 AI 繪圖工具快速做出全部角色的部件包，之後需要再人工精修。規格（部件清單、尺寸、命名）以 [ART_GUIDE.md](ART_GUIDE.md) 為準，這份只講 AI 流程的做法與要注意的地方。程式不綁定任何工具。

## 選工具

用**能拿參考圖、保持角色一致**的通用圖像模型，例如 ChatGPT 的 GPT Image、Google Gemini 的 Nano Banana、Flux 系列。
不適合：「精靈圖表（sprite sheet）產生器」——那是一格一格的動畫圖，我們是骨架動畫，要的是**分開的部件**。

開始前確認工具的**商用條款**（產出能不能用在販售的遊戲、能不能修改），寫進 `CREDITS.md`。

## 流程

### 1. 先做角色設定圖（最重要）

所有部件都以這張為準，畫風、配色、比例才會一致。

- 正側面全身（面向右）、手腳自然下垂、透明或純色背景
- 另外一張表情表（8 個表情，見 ART_GUIDE.md）
- 參考：`Character_design_sheet/chouma.png`（Chouma 的設定圖）、現在的佔位角色（`preview/gallery.html?char=chouma` 可以看比例）

把滿意的設定圖存進 `art_src/<角色>/reference/`，之後每次產生部件都附上這張當參考圖。

### 2. 一個部件一個部件產生

每次請 AI 只畫**一個部件**，並附上設定圖。提示詞要點（依工具調整）：

```
參考附圖的角色。只畫「上臂（肩膀到手肘）」這一個部件，其他部分都不要畫。
正側面、面向右、手臂自然垂直向下、不彎曲。
上端是圓的肩膀，下端要畫過手肘一點（會被前臂蓋住的部分也要畫）。
透明背景、置中、和附圖一樣的線條粗細與顏色、光從左上方來。
```

- **關節重疊**一定要講（AI 最常漏）：上臂畫過手肘、前臂畫過手腕、大腿畫過膝蓋、小腿畫過腳踝、身體的腰要和褲子重疊
- 頭、前髮、後髮**分三張**：頭（臉的底色、耳朵）、後面的頭髮、前面的頭髮；五官不要畫在頭上
- 手畫兩張：放鬆的 `hand`、比 YA 的 `hand@peace`

### 3. 表情

整張臉一張圖：附上設定圖與 `idle` 的臉，請 AI 「只改五官、臉框與大小完全不變」產生其他 7 個表情。
做不到「完全不變」時，可以只產生五官（透明背景），自己疊在 `idle` 的臉框上。

### 4. 預先產出（建議一次做完）

之後的功能會用到，現在一起產生最省事（匯入時會保留，見 ART_GUIDE.md「預先產出」）：

- `face_parts/`：眼睛（睜、半閉、閉）、**瞳孔另外一張**、眉毛 4 種、嘴型（閉、微笑、あいうえお）
- `hair_parts/`：長頭髮切 2～3 節
- `bust/`：**正面**上半身——AI 畫正面通常比側面好

### 5. 整理

| 問題 | 處理 |
|---|---|
| 背景沒有真的透明 | 用去背工具（例如 remove.bg、繪圖軟體的去背）；`art_check.py` 會抓「角落不透明」 |
| 白邊、霧邊 | 去背後把邊緣收縮 1～2 像素；`art_check.py` 會抓「白邊」「雜點」 |
| 每張的線條顏色、粗細不一樣 | 統一用繪圖軟體描一次外框，或調整色階；`art_check.py` 會抓「線條顏色差很多」 |
| 手指數量、左右手錯 | 人工修（AI 最常出錯的地方） |
| 尺寸太小 | 至少每 Q 版單位 2.5 像素（建議 4）；不夠就用放大工具或重新產生 |

存成 `art_src/<角色>/parts/<部件名>.png`、`faces/<表情>.png`。

### 6. 匯入、檢查、微調

```
python tools/import_layers.py art_src/<角色>
python tools/art_check.py art_src/<角色>      ← 看 build/art_check/<角色>.html
python tools/serve.py                          ← preview/gallery.html?char=<角色> 看全部動作
```

位置不對（例如手太低、頭太大）：在 `preview/editor.html` 的綁骨模式拖拉調整，存檔後重新匯入不會蓋掉調好的位置。

### 7. 記錄來源

`art_src/<角色>/CREDITS.md`：

```
# <角色> 美術來源
- 方法：AI 輔助（mixed）
- 工具：<工具名稱與版本>，產生日期 <YYYY-MM-DD>
- 人工修改：手指、外框線統一、表情的嘴型
- 參考：Character_design_sheet/<角色>.png（自有設計）
```

並在 `character.json` 的 `source` 寫 `{ "method": "mixed", "tools": ["<工具>"] }`。

## 從測試部件包換成精細圖

`art_src/chouma/` 現在是程式自動輸出的測試部件包（和佔位角色一模一樣），**檔名、位置都已經對好**：

1. 用上面的流程產生精細圖，**用同樣的檔名**覆蓋 `art_src/chouma/parts/`、`faces/` 裡的圖
2. 圖的大小和原本不一樣沒關係（會保持比例放進同樣的範圍）
3. `python tools/import_layers.py art_src/chouma` → `python tools/art_check.py art_src/chouma`
4. 重新啟動桌寵（打包版要重新打包：`powershell -File tools/build_release.ps1`）

其他角色：先輸出它們的測試部件包當起點（Godot：`--export-package=<角色> --out=art_src/<角色>`），再照同樣方式替換。
